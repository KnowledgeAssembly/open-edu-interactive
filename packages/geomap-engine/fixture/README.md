# Fixtures for GeoMap Engine

This directory contains golden fixtures for the GeoMap Engine.

## Structure

- `region/` — minimal region layer slice
- `marker/` — minimal marker layer slice
- `route/` — minimal route layer slice
- `odisha-coastal/` — integrated example with regions, markers, and labels

Each fixture has:
- `input.geomap.json` — the spec under test
- `validation.json` — expected validation result from `GeoMapEngine.validate`

The `expected.*.json` files are generated by the conformance pipeline and compared byte-stable by snapshot tests.

## Validation

```sh
pnpm --filter @knowledgeassemble/geomap-engine test
```

All fixtures must round-trip `GeoMapEngine.validate` as valid.
No fixture may contain authored geometry (`x`/`y`/`width`/`fill`/`stroke`).
